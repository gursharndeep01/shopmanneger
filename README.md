A full-stack MERN (MongoDB, Express, React, Node.js) shop management system


Track customers with complete payment history.Auto-calculating bills with tax and discounts and make record for paid , unpaid , partal transactions . maintain record for articles and their stock left . also generate professional printable invoices with auto calculation of amount.
React.js, React Router DOM, Axios, CSS3 Animations are used to complete frontend,
for backend Node.js, Express.js,MongoDB,Mongoose are used .
To start backend use npm run dev in backend terminal.
To start frontend use npm start in frontend terminal.
